## 工作流阶段

1. **Scope** — 拆解为 5 个搜索角度（产品功能 / AI 能力 / 商业模型 / 技术栈 / AI 辅助开发）
2. **Search** — 5 个并行搜索 agent
3. **Fetch** — 去重抓取 top 15 来源，提取可核查声明
4. **Verify** — 每条声明 3 票对抗性核查（≥ 2/3 refutes 则丢弃）
5. **Synthesize** — 合并去重、按置信度排序、生成引用报告

## 关键发现摘要

### ✅ 已核实（高置信度，多来源印证）

- **AI 搜索实验室**：性格 / 学历 / 工作 / MBTI / 生活习惯 五个维度
- **AI 分身**：用户可匿名向潜在对象询问资产 / 负债 / 情史 / 健康 / 彩礼等敏感问题；对方不知道具体提问者
- **1v1 匹配机制**：用户一次只能与一位匹配对象聊天，必须先释放当前匹配才能查看下一位
- **¥2000「保结婚会员」**：3 年内未领证结婚可全额退款（基于深圳约 150 对夫妻 70% 在 3 年内结婚的口径）

### ❌ 被反驳（仅单一来源 / 缺乏独立验证）

- "AI 红娘 20 分钟建档 / 平均资料 463 字 / 首批 82% 完成率 / 30.3 轮对话"
- LangGraph 7 节点工作流架构（来自第三方 GitHub 仓库的非官方推测）
- MongoDB + Elasticsearch + ChromaDB 三数据库架构（被反向证据推翻）

### ⚠️ 未确认（仅有 1 票）

- 2026-07-04 上线时间（仅搜狐转载提及）
- 完整 AI 能力边界（红娘 / 军师的具体对话模式）
