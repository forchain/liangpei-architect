# 模块 03 · IM（即时通讯）

## 范围

Chat 域负责 1v1 私聊会话、消息可靠送达、AI 军师触发、心有灵犀彩蛋。**禁止自建 WebSocket**（见 [ADR-006](../adr/0006-reject-self-built-im.md)）。

## 技术选型

| 决策 | 方案 | 理由 |
|---|---|---|
| 主链路 | **环信 IM SDK + UIKit**（专业版 < 1 万 DAU 免费） | SDK 一体化最成熟，HarmonyOS 覆盖 |
| 备选 A | 腾讯云 IM SDK | 深度微信生态集成需求时切换 |
| 备选 B | 融云 IM | 极端出海需求 |
| **不推荐** | 自建 WebSocket | 消息消失事故高发，断线重连至少耗 2 个月 |

## 技术方案

| 环节 | 方案 | 关键指标 |
|---|---|---|
| 主链路 | 环信 IM SDK + UIKit（专业版 < 1 万 DAU 免费） | 首响 < 200ms |
| 消息可靠 | SDK 内置 ACK / 漫游 / 多端同步 — 禁止自写 | 消息丢失率 < 0.01% |
| 离线推送 | 环信集成 APNs + 小米/华为/vivo/OPPO 通道 | 送达率 > 95% |
| 内容审核 | 发送前同步珊瑚 msgSecCheck；接收后异步复核 | RT < 200ms |
| AI 军师触发 | 聊天停滞 > 48h 自动推送"破冰建议" | 激活率 > 30% |
| 心有灵犀 | 双方 24h 内都问"对方是否对我有意"→ 双向解锁 | 留存 +20% |

## 数据模型

```sql
-- IM SDK 自带存储，本地只冗余索引用于业务查询
CREATE TABLE chat_sessions (
  id              TEXT PRIMARY KEY,           -- 环信会话 ID
  user_a          BIGINT REFERENCES users(id),
  user_b          BIGINT REFERENCES users(id),
  match_id        BIGINT REFERENCES matches(id),
  created_at      TIMESTAMPTZ,
  last_msg_at     TIMESTAMPTZ,
  state           SMALLINT                    -- 0 活跃, 1 已解除
);

CREATE TABLE chat_audit (
  id              BIGSERIAL PRIMARY KEY,
  session_id      TEXT REFERENCES chat_sessions(id),
  user_id         BIGINT,
  msg_text        TEXT,
  audit_result    JSONB,                      -- 命中关键词 + 风险等级
  created_at      TIMESTAMPTZ
);
```

## 关键流程

### 1v1 匹配成功 → 创建会话

```
Match 域确认匹配成功
  ↓
Chat 域调环信 API 创建会话 (POST /conversations)
  ↓
写入 chat_sessions 表
  ↓
双方推送"新匹配"通知
```

### 发送消息（含审核）

```
用户 A 发消息
  ↓
[同步] 珊瑚 msgSecCheck
  ├─ 命中 → 拦截 + 提示
  └─ 通过
      ↓
[SDK] 环信发送 (内置 ACK)
  ↓
[异步] 消息入库 + 异步复核
  ├─ 命中 → 撤回 + 封禁
  └─ 通过
      ↓
通知用户 B（含推送）
```

### 心有灵犀

```
用户 A 问 AI 军师："对方是否对我有意"
  ↓
记录 chat_audit.advisor_query_at
  ↓
检查对方 24h 内是否也问过
  ├─ 是 → 触发"心有灵犀"成就 → 双向解锁（看更多资料/发更多消息）
  └─ 否 → 正常返回
```

## AI 军师触发策略

| 触发条件 | 推送内容 |
|---|---|
| 聊天停滞 > 48h | "可以试试这几个话题：……" |
| 对方 24h 未回复 | "可能对方忙，可以再等一下" |
| 对方单条字数明显变少 | "感觉对方在犹豫，要不要直接问？" |
| 双方首次对话 | "破冰话题：……" |

## 推送通道配置

| 通道 | 适用 | 集成方式 |
|---|---|---|
| APNs | iOS | 环信自动 |
| 小米推送 | 小米手机 | 环信自动 |
| 华为推送 | 华为手机 | 环信自动 |
| vivo 推送 | vivo 手机 | 环信自动 |
| OPPO 推送 | OPPO 手机 | 环信自动 |
| 微信订阅消息 | 小程序 | 一次性订阅（避免骚扰） |

## API 设计

| Method | Path | 说明 |
|---|---|---|
| GET | `/api/v1/chat/sessions` | 会话列表 |
| GET | `/api/v1/chat/sessions/:id/messages` | 消息历史 |
| POST | `/api/v1/chat/advisor` | 触发 AI 军师 |
| POST | `/api/v1/chat/forward-anonymous` | AI 分身匿名转发 |

## 故障与降级

| 故障 | 降级 |
|---|---|
| 环信 API 不可用 | 客户端触发重连 + 拉离线消息 |
| 长连接大面积断 | 客服话术："消息可能延迟，请稍后查看" |
| 推送通道全挂 | 仅展示应用内消息 |
| 内容审核超时 | 放行 + 异步复核 + 风险标记 |
