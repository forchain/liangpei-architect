# 7×24 值班 Runbook（一人版精简）

> 一人开发 = 没有 7×24 = 必须有 5 分钟处置卡。

## 🔴 严重故障（影响全部用户）

### LLM 全挂

```yaml
症状: AI 红娘 / 军师 全部返回错误
影响: 100% AI 功能不可用
5min 处置:
  1. 看 AI Gateway 健康面板
  2. 切到备用供应商（config/llm.json 改 active_provider）
  3. 触发缓存兜底（本地 Redis 常见问答）
  4. 发状态页公告 + 客服话术
```

### 数据库不可用

```yaml
症状: 所有 API 返回 500
影响: 100% 业务不可用
5min 处置:
  1. 看 PG 主备状态
  2. 主库宕 → 改连接串到备库（手动 + 开启只读模式）
  3. 业务降级（匹配返回缓存）
  4. 启用 OSS 备份临时恢复（仅最近一次逻辑备份）
```

### 小程序被封

```yaml
症状: 用户突然无法访问
影响: 100% 用户无法登录
5min 处置:
  1. 看微信公众平台违规通知
  2. 立即下架违规内容
  3. 申诉（微信 7 天内回复）
  4. 同步检查所有用户协议 + 隐私协议
```

## 🟠 高优先级（影响部分用户）

### 支付回调大面积延迟

```yaml
症状: 用户支付后未开通会员
影响: 营收受损 + 用户投诉
5min 处置:
  1. 看微信商户平台回调日志
  2. 客户端启动轮询补偿（30s 一次 × 5 次）
  3. 跑对账 cron 比对订单
  4. 客服批量回复
```

### IM 长连接大面积断

```yaml
症状: 用户反映消息发不出去/收不到
影响: 核心功能不可用
5min 处置:
  1. 看环信控制台在线人数
  2. 客户端触发重连 + 拉离线消息
  3. 客服话术："消息可能延迟，请稍后查看"
```

### AI 红娘资料评分异常

```yaml
症状: 用户通过率突然下降/上升
影响: 资料质量不稳定
5min 处置:
  1. 看 ai_sessions 表异常评分率
  2. 切 prompt 版本（prompts/v1.x-matchmaker.md）
  3. 临时放宽阈值（70 → 60）
```

## 🟡 中等（影响个别用户）

### 内容审核误杀

```yaml
症状: 正常用户资料/消息被拦截
影响: 用户投诉 + 流失
5min 处置:
  1. 看 audit_logs 误杀率
  2. 加白名单关键词
  3. 调整阿里云 / 珊瑚策略阈值
```

### Apple IAP 退款但未通知

```yaml
症状: 用户已退款但会员状态未关闭
影响: 营收受损
5min 处置:
  1. 拉取 Apple 最新订阅状态
  2. 手动同步到 members 表
  3. 加 cron：每日主动 Verify Receipt
```

## 🟢 监控告警（早期发现）

| IM 在线跌幅 | > 15% | > 30% | > 50% |
| 越狱拦截 | > 5/h | > 10/h | > 50/h |

## 复盘流程（事故后 24h 内）

```yaml
0-2h: 紧急恢复
2-4h: 临时补丁
4-24h: 写事故报告
  - 时间线（精确到分钟）
  - 根因（5 Whys）
  - 影响范围（用户数 / 营收损失）
  - 防御动作（永久修复）
  - 责任归属（一人 = 都归你）
```

## 心理建设

> 一人开发的最大风险不是技术故障，是**精神疲劳**。

- 故障 < 30min 不算严重
- 用户投诉 < 5% 是正常的
- **周末不看 Sentry**
- 连续 3 个严重故障 → 强制休息一天
- 一个人扛不住就找朋友吐槽
