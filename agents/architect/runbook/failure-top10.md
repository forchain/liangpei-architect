# 故障 Top 10 与防御

> 一人开发的稳定性核心：**每个故障都假设凌晨 3 点发生**。

## #1 LLM API 全面不可用（🔴 严重）

**触发**：供应商限流 / 余额不足 / 区域故障 / SDK Bug

**防御**：
- 多供应商 fallback：**DeepSeek → 豆包 → Qwen**（config/llm.json 切换 active_provider）
- 本地缓存常见问答（Redis）
- 关键 prompt 模板预编译 + 离线兜底

**告警阈值**：错误率 > 5%

**5min 处置**：
1. 看 AI Gateway 健康面板
2. 切到备用供应商
3. 触发缓存兜底
4. 发状态页公告

---

## #2 ASR/TTS 静默丢音（🟠 高）

**触发**：网络抖动 / 用户静音 / 麦克风权限

**防御**：
- 客户端检测静音 > 3s 自动提示
- 服务端超时 8s 重连
- ASR 局部失败时切文本输入

**告警阈值**：静默率 > 15%

---

## #3 IM 断线消息丢失（🟠 高）

**触发**：杀后台 / 切网络 / 进程被回收

**防御**：
- **用 IM SDK 自带重连，禁止自写心跳**
- 多端同步（环信漫游）
- 离线推送（APNs + 小米/华为/vivo/OPPO）

**告警阈值**：离线时长 > 60s

**5min 处置**：
1. 看环信控制台在线人数
2. 客户端触发重连 + 拉离线消息
3. 客服话术："消息可能延迟，请稍后查看"

---

## #4 微信支付回调掉单（🟠 高）

**触发**：用户跳转前关闭 / 客户端崩溃

**防御**：
- 客户端跳转不立即开通，**等服务端回调**
- 30s 轮询订单（5 次）
- 服务端幂等表去重
- 每日对账 cron

**告警阈值**：回调 5min 未到

**5min 处置**：
1. 看微信商户平台回调日志
2. 客户端启动轮询补偿
3. 跑对账 cron 比对订单

---

## #5 AI 红娘卡在最后一题（🟡 中）

**触发**：LLM 超时 / 流中断 / 网络抖动

**防御**：
- 前端 30s 心跳重连
- **后端流式 token 必须续写，不能重发**（避免重复）
- 会话进度存 Redis，断点续传

**告警阈值**：会话 > 25min 未结束

---

## #6 向量检索冷启动慢（🟡 中）

**触发**：新用户无画像 / 数据库刚启动 / 索引未预热

**防御**：
- 启动时并发跑 100 个常用 query 预热
- 结果缓存 5min（Redis）
- pgvector 索引：`ivfflat lists=100`

**告警阈值**：P95 > 3s

---

## #7 滑卡下一页 N+1（🟡 中）

**触发**：未预计算匹配池 / 用户激增

**防御**：
- 每日 03:00 跑 Top-50 写 Redis
- 滑卡走 Redis 而非每次查询 PG
- 兜底：实时召回 + 标记降级状态

**告警阈值**：P95 > 1s

---

## #8 Prompt 注入攻击（🔴 严重）

**触发**：恶意用户在自画像/聊天中塞指令

**防御**：
- 前置审核 + 关键词黑名单
- LLM 重写层（用安全 LLM 重写可疑输入）
- **JSON Schema 强约束**（输出必须通过 Zod）
- 用户输入嵌入相似度检测

**告警阈值**：命中数 > 10/小时

---

## #9 数据库主从延迟（🟡 中）

**触发**：写入高峰 / 大事务

**防御**：
- 读强一致场景走主库
- 监控 `pg_stat_replication.replay_lag`
- 大事务拆分

**告警阈值**：延迟 > 2s

---

## #10 小程序审核被拒（🔴 严重）

**触发**：婚恋类目资质不全 / 内容违规 / 隐私协议缺失

**防御**：
- 提前挂靠主体（个人开发者强建议）
- 预留"陌生人社交"类目兜底
- 隐私协议 + 用户协议律师审核
- 算法备案 + 深度合成备案

**告警阈值**：审核失败即停
