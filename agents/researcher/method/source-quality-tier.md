# 来源质量分级

> Researcher Agent 引用来源时的分级标准。
> 决定一条事实能否进入 ✅ verified 状态的依据之一。

---

## 总览

| Tier | 等级 | 默认权重 | 典型来源 |
|---|---|---|---|
| **T1** | 一手 · 权威 | 高 | 政府文件、官方公告、财报 |
| **T2** | 二手 · 主流 | 中 | 央媒、36kr、财新、艾瑞 |
| **T3** | 三手 · 行业 | 中低 | CSDN、行业垂直媒体、知乎专栏 |
| **T4** | UGC · 自媒体 | 低 | 个人博客、公众号、知乎匿名 |
| **T5** | 不可靠 | 极低 | 营销软文、未署名转载 |

---

## T1 · 一手权威

> 直接发布事实的源头——政府、公司、监管机构。

| 典型来源 | 适用场景 |
|---|---|
| 国家统计局 / 民政部 | 人口、婚姻数据 |
| 工信部 / 网信办 / 央行 | 监管政策 |
| 公司官网 / 公告 | 公司基本面 |
| 上市公司财报 | 财务数据 |
| 工商登记信息 | 公司主体信息 |
| 应用商店 App 描述 | App 功能描述 |
| 学术论文（同行评议）| 技术 / 科学事实 |

### 引用规则

```
T1 单独即可作为 ✅ verified 的证据。
多个 T1 → 强 ✅ verified。
```

---

## T2 · 二手主流

> 主流媒体的独立采访 / 报道——通常有原始采访记录。

| 典型来源 | 适用场景 |
|---|---|
| 央媒（人民日报 / 新华社 / 央视）| 重大政策、社会事件 |
| 36kr / 财新 / 第一财经 | 创投资讯、商业模型 |
| 经济观察报 / 21 世纪经济 | 行业深度报道 |
| 艾瑞 / QuestMobile / 易观 | 行业研究报告 |
| The Information / Reuters / Bloomberg | 海外报道 |

### 引用规则

```
≥ 2 个独立 T2 → ✅ verified（前提是采访源独立）
单一 T2 → ⚠️ unverified
```

---

## T3 · 三手行业

> 行业垂直媒体、博客平台——内容质量参差。

| 典型来源 | 适用场景 |
|---|---|
| CSDN / 掘金 | 技术博客 |
| InfoQ / 极客邦 | 技术深度 |
| 雷锋网 / 虎嗅 | 科技 / 创业 |
| 行业垂直公众号 | 行业动态 |
| 知乎专栏（有实名专家背书）| 行业分析 |

### 引用规则

```
T3 通常作为「参考」而非「证据」——需配合 T1/T2 才能升 ✅
单独 T3 → ⚠️ unverified
```

---

## T4 · UGC / 自媒体

> 个人创作内容——质量依赖个人声誉。

| 典型来源 | 适用场景 |
|---|---|
| 个人博客 | 个人观点 |
| 公众号（无媒体背景）| 个人观点 |
| 知乎匿名回答 | 不可信 |
| GitHub 个人项目 | 仅作参考，非事实 |
| 论坛 / 贴吧 | 不可信 |

### 引用规则

```
T4 默认不作为事实证据。
仅作为「该话题有人讨论」的信号，不入档。
```

---

## T5 · 不可靠

> 营销软文、未署名转载、AI 生成内容未标注。

| 典型来源 | 适用场景 |
|---|---|
| 营销软文（推广产品）| 反向证据（产品自我宣传）|
| AI 生成内容未标注 | 不可引用 |
| 未署名转载 | 不可引用 |

### 引用规则

```
T5 默认不进入调研报告。
如果必须引用，需明确标注「营销倾向」/「未验证」。
```

---

## 来源交叉印证规则

### ✅ 升 verified 的最低组合

```
T1 × 1                       → ✅ verified
T2 × 2（独立）                → ✅ verified
T2 × 1 + T3 × 1（独立）       → ⚠️ unverified（边界情况）
T3 × N                        → ❌ 不足
T4 × N                        → ❌ 不足
T5 × N                        → ❌ 不可用
```

### 独立性要求

> 同一篇文章被多个来源转载**不算独立来源**。

```
❌ 反例：
  36kr 原创文章
  搜狐转载 36kr
  c114 转载 36kr
  → 3 个 URL，但只有 1 个独立来源

✅ 正例：
  36kr 原创文章
  c114 独立采访（采访对象不同 / 内容角度不同）
  腾讯应用商店 App 描述（独立来源）
  → 3 个独立来源
```

## 实操：判断一条来源的等级

### 5 个问题快速分级

```
Q1: 这条来源是发布事实的源头吗？
    是 → 至少 T1
    否 → Q2

Q2: 是主流媒体的独立采访 / 报道吗？
    是 → T2
    否 → Q3

Q3: 是行业垂直媒体 / 实名专家吗？
    是 → T3
    否 → Q4

Q4: 是个人创作吗？
    是 → T4
    否 → Q5

Q5: 是营销软文 / AI 生成 / 未署名吗？
    是 → T5
```

## 一句话原则

> **「一手 > 二手 > 三手 > UGC > 软文」** —— 引用时永远先找最高 tier 的来源。
> 高 tier 找不到再降级，但**永远不**接受 T5 来源作为事实证据。
